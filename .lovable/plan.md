# Apply the Instruct family branding to instructSiteEnterprise

## What you have
The full branding brief already exists as a standalone file in your Files: **Instruct-Family-AI-Build-Brief.md**. It contains every exact colour code, the wordmark rules, the 48px blueprint grid, button recipes for each surface, typography, navigation patterns, workflow doctrine, accessibility standards, and a copy-and-paste implementation prompt with placeholders for the product name and accent colour.

## Two ways to use it on instructSiteEnterprise

### Option A — you do it (about 2 minutes)
1. Open the instructSiteEnterprise project in Lovable.
2. Attach **Instruct-Family-AI-Build-Brief.md** to a chat message (paperclip / Files picker).
3. Say something like: "Apply this design system to this app. The product name is instructSiteEnterprise, the product accent is [your chosen colour]."
4. The brief's fill-in-the-blanks prompt at the end does the rest.

### Option B — I do it for you
I can open the instructSiteEnterprise project directly and apply the brief myself:
- Set up the shared Instruct tokens (navy, blueprint grid, typography) in that project.
- Apply the per-product accent slot with the colour you choose for Enterprise.
- Restyle its screens to the family standard (navy console, white working screens, light documents).
- Verify it builds cleanly.

## One decision needed either way
**What is instructSiteEnterprise's accent colour?** The family rule is: "instruct" stays white, and each product name owns its own bright accent (instructBrain uses Laser Green #57FF00). Enterprise needs its own — for example a gold, cyan, or violet. Tell me the colour (or a hex code) and I'll fill that slot.

## Recommendation
Option B is safer — I wrote the brief and know exactly which parts are rules versus guidance, and I can verify the result builds and looks right. If you approve, tell me the accent colour and I'll switch to that project and apply it.
